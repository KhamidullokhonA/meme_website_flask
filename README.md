# Flask Meme App

A simple Flask web application that fetches random memes from an API and displays the meme along with its subreddit.

## Features

- Fetches a random meme
- Displays the subreddit
- Automatically refreshes every 30 seconds

## Technologies

- Python
- Flask
- HTML/CSS
- Meme API

## How to Run

1. Install dependencies:

   pip install flask requests

2. Run the application:

   python meme_flask.py

3. Open the app in your browser.
